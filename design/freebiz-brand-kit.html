Freebiz is a billboard the whole internet watches together. Brands buy sixty seconds. Viewers catch what falls off the frame. The identity has one job: make a code on screen feel like money on the table.

01

The logo

Two parts. The mark is an open hook catching a falling disc — the act the whole product is built on, drawn with no container around it so it can never be mistaken for an app-store squircle. The wordmark sets freebiz in lowercase, and the dot over the i is a second freebie: the only yellow in the wordmark, sitting loose above the word, waiting to be taken. See freebiz-logo-concepts.html for the four alternates — the mark is a single SVG swap everywhere.

App icon & favicon

Mark only. Two heavy round-capped strokes and a disc — it holds at 16px because there is nothing thin in it.

Rules

  • Do keep clear space equal to the height of the mark on all four sides.
  • Do set the wordmark at 22px or larger so the freebie dot stays visible.
  • Don't make the dot any colour but Freebie Yellow. It is the only yellow allowed in the logo.
  • Don't add a gradient, glow, drop shadow or a box around the mark. The open form is the point.
  • Don't capitalise it. It is freebiz, never Freebiz, in the logo — sentence case is fine in body copy.

02

Colour

The base is a purple-black — a screen glowing in a dark room, not a black rectangle. On top of it, four colours that each mean exactly one thing everywhere in the product. Colour is state, never decoration: if something is yellow, it is a reward that has not been taken yet.

One rule worth repeating

Mint means take it. Red means it's gone. This single pair does more work than any other decision in the product — a viewer scanning the board should know in half a second which codes are still worth typing.

03

Typography

Three faces, three jobs. A display face with a bit of wobble in it so headlines feel like a person shouting rather than a corporation announcing. A tight grotesque for everything you actually read. And a monospace for anything a viewer has to type or trust — codes, PINs, amounts, invoice numbers.

04

Voice

Freebiz talks like the friend who tells you a shop is doing free jollof on Friday — direct, a little urgent, never pretending. Short sentences. Plain verbs. Say the actual amount and the actual rule. No exclamation marks, because the product is already exciting and punctuation shouting on top of it reads desperate.

Write this

Nothing you win ever expires.
1 cash + 1 airtime a day, per person.
The code is gone. Somebody was faster.
Send the code for review.

Not this

Rewards subject to validity period.
Daily claim quota enforced per user.
Oops! This code is no longer available 😢

05

Design tokens

Drop this straight into the app. Route themes are set by overriding --accent on a wrapper element, which is why one component library serves all three routes.

/* freebiz.tokens.css */
:root{
  /* base */
  --ink-900:#0E0C16; --ink-800:#14111F;
  --ink-700:#1C1830; --ink-600:#272041;
  --line:rgba(255,255,255,.09);
  --line-2:rgba(255,255,255,.16);

  /* ink */
  --txt:#EFECF7; --muted:#9C96B8; --faint:#6E688A;

  /* meaning */
  --free:#FFD23F;   /* unclaimed reward   */
  --brand:#7C5CFF;  /* brand-side action  */
  --live:#3DDC97;   /* open, approved     */
  --spent:#FF4D5E;  /* claimed, rejected  */
  --admin:#4CC9F0;  /* control room only  */

  /* route accent — remapped per route wrapper */
  --accent:var(--free);
  --accent-soft:rgba(255,210,63,.14);

  /* shape & depth */
  --r-sm:8px; --r:14px; --r-lg:22px;
  --shadow:0 18px 50px -18px rgba(0,0,0,.75);

  /* type */
  --display:'Bricolage Grotesque',system-ui,sans-serif;
  --body:'Inter Tight',system-ui,sans-serif;
  --mono:'JetBrains Mono',ui-monospace,monospace;
}
